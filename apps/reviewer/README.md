# AI Reviewer GitHub App — GOV-003A offline MVP

**Status: source and synthetic tests only; no App registration, installation, webhook endpoint or AI runtime is active.** The current delivery flow is Codex/Claude Code (or another authorized implementation provider) opening a PR under an independent GitHub identity, followed by AI review and a human approval/merge. The GOV-001A Implementer App source remains in this repository but is deferred in the current workflow.

`internal/reviewer` supplies a provider-neutral `Engine` interface, a signed `pull_request` webhook handler, a bounded asynchronous queue, an orchestrator and a private GitHub adapter. The four accepted actions are `opened`, `synchronize`, `ready_for_review` and `reopened`. Draft PRs are skipped. The handler validates the installation, numeric repository ID, allowed full name, protected `master` base, head/base SHA and delivery ID before enqueueing. The framework verifies HMAC-SHA256. No PR code is executed.

The orchestrator fetches the exact PR head, bounded file patches and requirements from the protected base SHA. It treats the PR body and diff as untrusted data, checks the head again before reporting and attaches a Check Run to that exact SHA. A completed review with BLOCKER/MAJOR findings is `BLOCKED`; completed analysis without them may be `READY_FOR_HUMAN_REVIEW`, which is only advisory. Missing evidence, engine failure or no approved engine yields `REVIEW_UNAVAILABLE` with an `action_required` check conclusion. `UnavailableEngine` is the only runtime engine included; the deterministic fake is test-only. No CLI or paid API is invoked.

The reviewer can create a Check Run, including up to 20 validated findings and annotations on added lines. It cannot submit a GitHub `APPROVE` review, edit PRs, merge, push code, alter repository settings or act as the Human Gate Owner. Proposed permissions are [recorded here](../../docs/security/reviewer-permissions.md). The [architecture boundary](../../docs/architecture/reviewer-boundary.md) records queue, retry, custody, context and activation limits. The [ADR](../../docs/decisions/0003-ai-reviewer.md) records framework choices and unresolved decisions.

An actual local/subscription-backed CLI adapter is deferred. Before adding one, the owner must approve its terms, unattended use, runtime authentication and cost; it must run in an isolated process without App tokens, private key or webhook secret. A trusted bridge may pass only bounded review input and validated output. No deployment executable or live network path is enabled by GOV-003A.
